00

La idea en una frase

Web scraping juridico responsable

Es revisar automaticamente paginas oficiales, leer sus publicaciones, identificar las novedades relevantes, descargar solo documentos publicos, registrar evidencia y generar un reporte trazable.

No reemplaza criterio legal

Automatiza vigilancia documental; la interpretacion juridica sigue siendo humana.

No todo lo nuevo es relevante

La regla juridica define que documentos entran, cuales se excluyen y por que.

La fecha manda

Usa la fecha oficial de publicacion de la pagina, no la fecha del PDF.

01

Herramientas que debes tener antes de empezar

Python 3.12+

Lenguaje donde vivira el monitor. Permite descargar paginas, leer HTML, guardar PDFs y generar reportes.

VS Code o Cursor

Editor para abrir el proyecto, revisar archivos y conversar con la IA sobre cambios concretos.

Git y GitHub

Control de versiones, historial de cambios y ejecuciones programadas con GitHub Actions.

Terminal

Ventana donde ejecutas comandos como instalar dependencias, correr pruebas y lanzar el monitor.

Chrome o Edge

Para inspeccionar si la informacion esta en HTML, en un endpoint interno o cargada por JavaScript.

Vercel o GitHub Pages

Opcional: publicar manuales, dashboards o reportes estaticos para el equipo legal.

04

Que hace tecnicamente la IA cuando construye el scraper

Requests / HTTPLa IA pide la pagina igual que un navegador, pero sin abrirla visualmente.
BeautifulSoupLee el HTML y ubica titulos, fechas, enlaces y texto relevante.
SQLiteGuarda que documentos ya fueron detectados para no repetirlos.
SHA-256Huella digital del archivo: si cambia el PDF, cambia el hash.
pytestPruebas automatizadas que avisan si una regla se rompe.
GitHub ActionsEjecuta el monitor en una fecha programada, sin que alguien lo haga manualmente.
05

Implementacion minima que debe pedir un abogado

1. Configuracion

URLs, zona horaria, carpeta de salida, User-Agent, reintentos y pausas.

2. Extractor

Reglas para leer listados, abrir detalles y encontrar fecha oficial y PDF.

3. Clasificador

Convierte titulos y colecciones en categorias juridicas del reporte.

4. Repositorio

Base SQLite con URL canonica, id de portal, hash, estado y ultima revision.

5. Reporte

Markdown y JSON con novedades, errores, fuentes consultadas y ausencia expresa.

6. Scheduler

Comando manual y ejecucion programada, normalmente en GitHub Actions.

Comandos de operacion 
python -m anpd_monitor validate-sources
python -m anpd_monitor run --dry-run --days 7
python -m anpd_monitor run --days 7
python -m pytest
python -m ruff check .
06

Controles legales y de calidad

Fecha no verificable No descargar automaticamente; enviar a revision manual.
Fuente cambia estructura Alertar si antes habia resultados y ahora no se extrae nada.
Documento duplicado Comparar URL, id del portal y hash SHA-256.
Archivo falso Rechazar HTML guardado como PDF y validar firma del archivo.
Falla parcial Continuar con otras fuentes y registrar el error de la fuente fallida.
Uso no responsable Usar pausas, User-Agent identificable, timeouts y reintentos moderados.
